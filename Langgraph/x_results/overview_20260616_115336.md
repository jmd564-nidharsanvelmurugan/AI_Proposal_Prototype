# Overview

PURE FINANCIAL ADVISORS LLC’s data, technology, and marketing teams currently manage the firm’s lead‑to‑asset‑under‑management (L2A) pipeline and customer acquisition reporting processes. These functions rely on a set of connected systems that support both client relationship management and financial tracking across the organization.  

The firm’s operational ecosystem includes Salesforce for CRM, Tamarac for portfolio management, Azure Blob Storage for raw data storage, Microsoft Fabric and Azure Synapse as the core data platforms, and Power BI as the primary reporting and analytics tool. QuickBooks is also part of the financial data landscape and is planned for integration into the broader reporting environment.  

Underlying data sources span Salesforce, Tamarac, Azure Blob Storage, and QuickBooks, all hosted within the Microsoft Azure infrastructure. Current integration efforts focus on connecting QuickBooks data and assessing its quality to support consistent reporting across systems. No manual processes or data governance policies are specified in the current documentation.
