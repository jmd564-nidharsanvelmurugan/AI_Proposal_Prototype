# Overview

PURE FINANCIAL ADVISORS LLC’s current reporting environment spans multiple internal teams, primarily data, technology, and marketing, which collaborate to manage pipeline and customer acquisition reporting. These teams rely on a connected ecosystem of platforms including Salesforce, Tamarac, Azure Blob Storage, Microsoft Fabric, Azure Synapse, Power BI, and QuickBooks (pending integration). Each system plays a role in capturing and storing client, financial, and operational data that feeds into the firm’s analytics processes.

The organization’s reporting is delivered through a Power BI suite, drawing from several primary data sources—Salesforce, Tamarac, Azure Blob Storage, and QuickBooks. Underpinning these systems is a Microsoft-based cloud infrastructure centered on Fabric and Synapse, supporting data ingestion and transformation activities. While manual processes are not specified, integration challenges exist around connecting and ingesting QuickBooks data and ensuring data quality for customer acquisition cost reporting.
