# Overview

PURE FINANCIAL ADVISORS LLC’s current reporting environment spans multiple internal teams and systems, with data, technology, and marketing teams jointly responsible for managing pipeline and customer acquisition reporting. The firm’s operations rely on a connected ecosystem of platforms including Salesforce, Tamarac, Azure Blob Storage, Microsoft Fabric, Azure Synapse, Power BI, and QuickBooks (pending integration). These systems collectively support client relationship management, portfolio tracking, data storage, and financial accounting functions.  

The existing reporting suite is built in Power BI, leveraging data sourced primarily from Salesforce, Tamarac, Azure Blob Storage, and, once integrated, QuickBooks. Microsoft Fabric and Azure Synapse form the core of the cloud and data platform infrastructure, providing the foundation for data ingestion, transformation, and analytics. Integration challenges currently center on connecting QuickBooks and ensuring data quality to support accurate reporting. No manual processes or data governance policies are explicitly documented at this stage.
