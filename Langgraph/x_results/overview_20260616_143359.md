# Overview

PURE FINANCIAL ADVISORS LLC’s current reporting environment spans multiple teams and systems, with data, technology, and marketing teams jointly responsible for pipeline and customer acquisition reporting. The firm’s data ecosystem integrates several core platforms, including Salesforce for CRM, Tamarac for portfolio management, Azure Blob Storage for data storage, Microsoft Fabric and Azure Synapse for data processing, and Power BI as the primary reporting and analytics tool.  

Operational data is sourced from Salesforce, Tamarac, Azure Blob Storage, and QuickBooks, which is in the process of being integrated into the broader reporting framework. The Microsoft Fabric and Azure Synapse platforms form the foundation of the firm’s cloud infrastructure, supporting data ingestion and transformation activities. Integration challenges currently center on connecting and ingesting data from QuickBooks and ensuring data quality to support customer acquisition cost reporting. No manual processes or data governance policies are specified in the current documentation.
